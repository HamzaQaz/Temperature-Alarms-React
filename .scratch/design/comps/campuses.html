About this comp

Audience
IT leadership: a director or network manager who wants the district's state in one look, weekly or before a meeting, without opening twenty-nine cards.
Job
Know which Campuses need attention, how the week has trended, and how long each has gone without trouble.
Key decision
A plain table, one row per Campus, worst first, with a one-sentence summary above it instead of hero tiles. The 7-day trend is a labelled column chart of each day's worst high against the Hot warning line, so it reads as evidence, not decoration. "Since last incident" is the calm number leadership actually asks for.
Relies on
  • No SaaS hero metrics: the summary is a sentence, the numbers live in the rows.
  • One Meaning: amber only on days and rows that were in a warning Condition.
  • Tabular figures in every column; 14px floor in the table.
  • The Reading-landed wash when a worst closet updates.
Would change
  • A fourth nav item (Campuses) beside Dashboard, History and Settings.
  • DESIGN.md's charts section covers day charts only; a small per-row column chart is a new chart type to document.
Server needs
A per-Campus endpoint: counts per Condition now, the worst Device, each day's highest Reading for 7 days with whether that day was in a Condition, and the end of the last incident. The browser totals nothing it cannot see.
