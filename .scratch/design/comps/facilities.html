About this comp

Audience
HVAC and facilities staff, on a phone in a corridor or at a desk, who fix rooms, not networks.
Job
Find the room, see how long it has been wrong and which way it is heading, and know what to look at first when they get there.
Key decision
The closet is addressed the way facilities finds it: Campus, building, floor, room, with the network name second. Each item answers four questions in reading order (where, how bad and how long, which way, what to check), and the "what to check" list is plain language per Condition. Hostnames, Online badges and the Offline Condition are hidden; an offline sensor is one quiet line handed back to the technicians.
Relies on
  • Worst Wins on each item's border; badges keep the level in words.
  • Display type for the one number that matters, 48px, tabular.
  • Chart colours: Signal Blue for temperature, Humidity Green dashed for humidity, the threshold dashed grey.
  • Grey primary-less page: the only button per item is an outline "Copy for a work order".
Would change
  • CONTEXT.md has no building or room: a Closet would need a location the facilities team recognises, entered in Settings.
  • "What to check" is copy owned by facilities, per Condition; it should come from the server with the Condition so it is the same everywhere.
  • A role or view without the technician pages, which the product does not have today (one shared Admin token, no login).
Server needs
Condition start time per Device (for "out of range for"), the last 6 hours of Readings, the threshold that was crossed, and the location fields above.
